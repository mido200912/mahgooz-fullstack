# محجوز MAHGOOZ — نسخة متصلة بقاعدة بيانات محلية

منصة حجز مناسبات كاملة: واجهة عربية (HTML/CSS/JS) + API (Express) + قاعدة بيانات SQLite.

## المتطلبات

- Windows 10/11
- **Node.js 24 LTS** (الحد الأدنى 22.5 لأن المشروع يستخدم `node:sqlite` المدمجة بدون أي حزم native)
- اتصال إنترنت أول مرة لتنزيل الحزم والصور

## التشغيل السريع

1. افتح مجلد `mahgooz-fullstack`.
2. شغّل `run.bat` (يثبت الحزم تلقائيًا ثم يشغل السيرفر ويفتح المتصفح).
3. أو من Terminal:

```bash
npm install
npm start        # http://localhost:3000
npm run dev      # إعادة تشغيل تلقائية عند تعديل server.js
```

قاعدة البيانات `data/mahgooz.sqlite` تُنشأ تلقائيًا وتُملأ **مرة واحدة فقط** بالأماكن والباقات التجريبية. البيانات المحفوظة (الحسابات، الحجوزات، المفضلة) تبقى بعد إغلاق السيرفر. لإعادة التهيئة من الصفر: أوقف السيرفر واحذف مجلد `data`.

## الروابط

- الموقع: <http://localhost:3000>
- لوحة الإدارة: <http://localhost:3000/admin.html>
- فحص الـ API: <http://localhost:3000/api/health>

### حساب المدير الافتراضي

- البريد: `admin@mahgooz.local`
- كلمة المرور: `Admin1234!`

> بيانات دخول افتراضية للتطوير المحلي فقط، غيّرها قبل أي نشر.

## المزايا

- عرض الأماكن والباقات من قاعدة البيانات مع فلاتر (المناسبة، المدينة، عدد الأفراد) وبحث.
- تفاصيل كل مكان في نافذة منبثقة مع زر حجز.
- تسجيل حساب/دخول بكلمات مرور مشفرة (bcrypt) وجلسات JWT صالحة 7 أيام.
- حفظ الحجوزات في SQLite مع منع تعارض نفس المكان/التاريخ/الوقت والتحقق من السعة.
- قائمة "حجوزاتي" مع إمكانية إلغاء الحجز.
- مفضلة لكل مستخدم (إضافة/إزالة).
- لوحة إدارة: إحصاءات، متابعة الحجوزات وتغيير حالتها، إضافة الأماكن، إظهار/إخفاء الأماكن.
- واجهة عربية RTL متجاوبة مع نفس الهوية البصرية (أخضر `#073b36`، خط Tajawal).

## هيكل المشروع

```
mahgooz-fullstack/
├─ server.js          # Express + SQLite + JWT + كل مسارات API
├─ data/              # قاعدة البيانات (تُنشأ تلقائيًا)
├─ public/
│  ├─ index.html      # الصفحة الرئيسية (تصميم + مودالات)
│  ├─ app.js          # ربط الواجهة بالـ API
│  └─ admin.html      # لوحة الإدارة
├─ run.bat            # تشغيل بنقرة واحدة على Windows
└─ package.json
```

## API مختصر

| Method | المسار | الوصف |
| --- | --- | --- |
| GET | `/api/health` | فحص حالة السيرفر وقاعدة البيانات |
| GET | `/api/venues?city=&tag=&guests=&q=` | الأماكن النشطة مع فلاتر |
| GET | `/api/venues/:id` | تفاصيل مكان |
| GET | `/api/packages` | الباقات |
| POST | `/api/auth/register` | إنشاء حساب وإرجاع token |
| POST | `/api/auth/login` | تسجيل الدخول |
| GET | `/api/auth/me` | بيانات المستخدم الحالي |
| POST | `/api/bookings` | إنشاء طلب حجز |
| GET | `/api/bookings/mine` | حجوزات المستخدم |
| PATCH | `/api/bookings/:id/cancel` | إلغاء حجز |
| GET | `/api/favorites/mine` | المفضلة |
| POST/DELETE | `/api/favorites/:venueId` | إضافة/إزالة من المفضلة |
| GET | `/api/admin/stats` | إحصاءات (مدير) |
| GET | `/api/admin/bookings` | كل الحجوزات (مدير) |
| PATCH | `/api/admin/bookings/:id/status` | تغيير حالة حجز |
| GET/POST | `/api/admin/venues` | عرض/إضافة أماكن |
| PATCH/DELETE | `/api/admin/venues/:id` | تعديل/إخفاء مكان |

المسارات المحمية تحتاج ترويسة: `Authorization: Bearer <token>`.

## ملاحظات

- بيانات الأماكن والأسعار تجريبية وليست منشآت حقيقية أو أسعار مؤكدة.
- الحجز يسجل الطلب في قاعدة البيانات فقط؛ لا يوجد إشعار لمكان حقيقي أو بوابة دفع.
- الصور تُحمّل من Unsplash وتحتاج اتصال إنترنت.
- قبل النشر العام: اضبط `JWT_SECRET` عبر متغير بيئة، غيّر كلمة مرور المدير، أضف HTTPS وحدود معدل الطلبات.

## حل المشاكل

- **المنفذ 3000 مشغول:** أغلق السيرفر القديم أو شغّل `PORT=3001 npm start`.
- **Node قديم:** ثبّت Node.js 24 LTS.
- **الواجهة لا تعرض البيانات:** افتح `/api/health` وتأكد أن السيرفر يعمل، ثم أعد تحميل الصفحة.
